Como funciona

Você descreve o trabalho uma vez. Ele roda quando precisa.

Assistente de IA hoje é conversa: você abre, pede, espera e copia. O Locum inverte isso. O agent roda sozinho quando chega um PR, uma mensagem ou a hora marcada, e entrega o resultado onde você decide.

Local primeiro

Banco SQLite, credenciais no Keychain do macOS e execução na sua máquina. Não existe servidor do Locum no meio.

Nada sai sem você

Comentar no GitHub, responder no Slack ou abrir um card passa por uma porta única de aprovação. Cada passo escolhe aprovar, rascunho ou automático.

Você monta, ele não inventa

O Locum entrega as peças e você decide como encaixar. Filtro, horário, modelo e texto ficam à vista no fluxo. Nada acontece que você não montou.

Fila

O que vai sair, antes de sair.

Cada resposta, review ou card que o agent prepara para na Fila com o texto exato que vai ser publicado. Você edita, aprova ou descarta. Também pelo teclado, e pela bandeja do Mac.

  • Texto editável. O que você mudar é o que sai.
  • Modo por passo. Aprovar, rascunho ou automático, escolhido em cada ação do fluxo.
  • Rastro completo. Cada item leva para a execução que o produziu, com custo e saída de cada passo.
Peças

Seis peças, montadas do seu jeito.

Cada automação é um fluxo de nós que você vê, configura e apaga. Os modelos prontos já vêm montados, e continuam editáveis.

GatilhosPR novo no GitHub, menção no Slack ou no Teams, horário marcado.
AgentsPassos com modelo, ferramentas e orçamento próprios. Nascem de um formulário ou de uma descrição em texto.
AçõesPublicar a review, responder no canal, abrir a tarefa, chamar uma API. Todo efeito fora da máquina é um nó.
FerramentasServidores MCP com OAuth de um clique: GitHub, Atlassian, Linear, Notion, Sentry, Figma e outros.
LógicaCondição, filtro e desvio entre os passos, com o critério escrito no nó.
AprovaçãoA Fila mostra o texto ou o diff que vai sair, editável antes de publicar.

Conexões

Onde o seu trabalho já está.

GitHub, Slack e Microsoft Teams para ler e responder. Servidores MCP remotos com OAuth de um clique para o resto, e qualquer servidor MCP seu fora do catálogo.

Claude Code

Monte conversando.

O Locum tem servidor MCP próprio, ligado no Claude Code com um clique. Tudo que a tela configura, o MCP configura também.

  • Paridade com a tela. Gatilho, agent, automação e iniciativa saem da conversa.
  • Iniciativas. Uma frente de trabalho com contexto e servidores MCP próprios, aberta no Claude Code já com esse contexto.
  • Sessões. As conversas do Claude Code da máquina, com as que pararam no meio e as que esperam resposta.

Instalar

Quatro passos, uma vez só.

Hoje há pacote para Mac com Apple Silicon. Depois de instalado, o Locum se atualiza sozinho a cada versão.

  1. Baixe o .dmgPelo botão acima. As versões anteriores ficam na lista abaixo.
  2. Arraste para AplicativosComo qualquer app do Mac.
  3. Botão direito, AbrirO Locum é assinado pelo próprio projeto, não pela Apple. O macOS pede essa confirmação só na primeira vez.
  4. Conecte e monteLigue o GitHub e um provedor de modelo, instale um modelo pronto e veja o primeiro item chegar na Fila.
